# 📈 StockPulse Analytics

A financial analytics dashboard built with Streamlit for analyzing stock performance, company fundamentals, and future stock price trends.

## 🚀 Features

- Real-time stock analysis
- Revenue & growth tracking
- Multi-company comparison
- Risk & volatility insights
- 30-Day stock forecasting

## 🛠️ Tech Stack

Python • Streamlit • Pandas • Plotly • yFinance • Prophet
